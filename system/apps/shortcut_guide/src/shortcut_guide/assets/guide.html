Return to the conversation

One key press back to the right chat.

From any Mac app, Option+N brings Studio forward and raises chat in the machine you selected. Press it again and the same chat comes back.

Option+N→Current machine’s chat

The working prototype raises chat. It does not open a new note or place the typing cursor in the chat box.
